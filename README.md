# internaltooling.github.io

Personal site of internaltooling, kept as the front page of an internal server. Plain HTML, no build step.

- **Main inspiration:** [tilde.town](https://tilde.town), found on [brutalistwebsites.com](https://brutalistwebsites.com). From it: the home page of a shared server, with a right-aligned `~user` rail, an ASCII banner, boxes on a field of dots (one dot per user, and here one dot is lit), a live `uptime` line and a row of 88x31 badges. The gallery notes are in `/data/pages-refresh/internaltooling-gallery-notes.md` on the hub.
- **Typefaces:** Red Hat Mono from [Google Fonts](https://fonts.google.com/specimen/Red+Hat+Mono), for everything. SIL OFL 1.1, self-hosted in `assets/fonts/` with its licence beside it. The banners are figlet's "Mini" font, set as text.
- **Theme:** the intranet of a company of one: an internal server's front page with a user directory that lists one user. Light is boxes on grey paper. Dark is boxes on a near-black dot field. The footer badges hold the theme toggle. `control ⌘K` opens the palette. Escape on a filing goes back to the index.
