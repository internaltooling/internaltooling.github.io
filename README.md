# internaltooling.github.io

Personal site of internaltooling, kept as a registry. Plain HTML, no build step.

- **Main inspiration:** [Typical Organization](https://typical-organization.com/), found on [brutalistwebsites.com](https://brutalistwebsites.com). From it: one grotesk at one size, a 7-column grid of hairline boxes, Date / Object / Subject / Control rows with a hairline on hover, and entries that open as a white sheet over an inverted page, with Escape / Future / Past. The gallery notes are in `/data/pages-refresh/internaltooling-gallery-notes.md` on the hub.
- **Typefaces:** Ronzino from [Collletttivo](https://collletttivo.it) for everything, and Martian Mono by Evil Martians, found on [Uncut](https://uncut.wtf), for code only. Both are SIL OFL 1.1 and self-hosted in `assets/fonts/`, with their licences beside them.
- **Theme:** black on white, no accent colour. The dark theme inverts it. Filings and the 404 are sheets on the inverted page. The Control column opens the ⌘K palette. Escape on a sheet goes back to the index.
