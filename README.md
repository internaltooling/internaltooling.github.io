# internaltooling.github.io

Personal site of internaltooling, kept as a file marked internal. Plain HTML, no build step.

- **Typefaces:** [Redaction](https://www.redaction.us/) by MCKL for all text, and its degraded grade Redaction 70 for the name at the top of the home page and the 404. [Necto Mono](https://collletttivo.it/typefaces/necto-mono) by Collletttivo for numbers, dates, keys and code. Both are SIL OFL 1.1 and self-hosted in `assets/fonts/` with their licences beside them. Redaction has no arrows, so the text stack falls back to Necto Mono for ← → ↗.
- **References:** [Soft Labor](https://www.softlabor.biz/) (hoverstat.es) for the name set large in a broken-down grade, [Satoshi Watanabe](https://satoshiwatanabe.org/) (siteinspire.com) for the numbered index with short column heads, [Optikarchiv](https://optikarchiv.com/) (minimal.gallery) for one strict grid with very few sizes, and [Adrian Schaedle](http://adrian.schaedle.me) (brutalistwebsites.com) for the dot field, here the uptime dots.
- **Art:** three Calvin and Hobbes images by Bill Watterson, shown as exhibits: the cardboard-box time machine on the home page, the duplicator in RFC-0003, and the last strip (1995.12.31) on the 404. They are credited in their captions, self-hosted as WebP in `assets/art/` with metadata stripped, and stay © Bill Watterson. They are grey at rest where a pointer can hover and in colour on hover. The palette's theme toggle answers to "transmogrify".
- **Theme:** dark by default, light on request, remembered. One accent, a stamp red, for links on hover, the current page, the focus ring and "internal use only". The grid, type scale, spacing and colours are custom properties at the top of `assets/site.css`, and the rest of the file uses only those. The clean grade of the name fades in on hover. One record value is redacted until hovered, focused or tapped. `⌘K` opens the palette.
