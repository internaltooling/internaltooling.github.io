# internaltooling.github.io

Personal site of internaltooling, kept like a notebook on warm paper: the fleet's records, drawn by hand. Plain HTML, no build step.

- **Typefaces:** [Fraunces](https://github.com/undercasetype/Fraunces) by Undercase Type for text and titles, pinned soft (SOFT 100, WONK 0), with optical sizes 9–144 and weights 300–700. [Shantell Sans](https://github.com/arrowtype/shantell-sans) by Shantell Martin and Arrow Type for the hand-lettered parts: the name in the header, nav, labels, notes, numbers and stamps, with weights 400–700 and its informality axis kept. Both are SIL OFL 1.1, subset to Latin and self-hosted in `assets/fonts/` with their licences beside them. Fraunces has no arrows, so the text stack falls back to Shantell Sans for ← → ↗. [Necto Mono](https://collletttivo.it/typefaces/necto-mono) (OFL) stays only for code blocks, where columns must line up.
- **References:** [iamrobin](https://iamrob.in) (minimal.gallery) for the highlighter stroke behind one phrase and the dashed, form-like rules, [Pavel Kedzich](https://kedzich.com) (httpster.net) for a warm serif system with small labels and one orange accent, and [mellow](https://mellow.dev) (minimal.gallery) for the cream page and the quiet, friendly tone.
- **Art:** three Calvin and Hobbes images by Bill Watterson, shown as exhibits: the cardboard-box time machine on the home page, the duplicator in RFC-0003, and the last strip (1995.12.31) on the 404. They are credited in their captions, self-hosted as WebP in `assets/art/` with metadata stripped, and stay © Bill Watterson. They sit on the page as taped-in cards, in full colour. The palette's theme toggle answers to "transmogrify".
- **Theme:** day (warm paper with a faint grain) by default, night (deep blue ink) on request, remembered. One accent, a tiger orange, for links, the current page, the focus ring, list numbers and the "internal use only" stamp. Section rules are a drawn pen line (an inline SVG), row rules are dashed. The grid, type scale, spacing and colours are custom properties at the top of `assets/site.css`, and the rest of the file uses only those. On hover, the big name is lettered again by hand. One record value is redacted until hovered, focused or tapped. `/` or `⌘K` opens the palette.
