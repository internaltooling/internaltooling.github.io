# internaltooling.github.io

Personal site of internaltooling, kept as a catalog of internal tools. Plain HTML, no build step.

- **Main inspiration:** [Whole Earth Index](https://wholeearth.info/), found on [siteinspire.com](https://www.siteinspire.com/). From it: one serif at a small number of sizes, a single mono italic line for notes, a hairline-ruled grid of titles with small index numbers, then one section per title with its label in the first third and its text in the middle. Book details too: oldstyle figures, hyphenation, indented paragraphs. The gallery notes are in `/data/pages-refresh/internaltooling-gallery-notes.md` on the hub.
- **Typefaces:** [Source Serif 4](https://fonts.google.com/specimen/Source+Serif+4) for text and [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) for notes, figures, keys and code, both from Google Fonts. SIL OFL 1.1, subset to Latin-1 plus the site's symbols (⌘ · — ← → ↗ and box drawing), self-hosted in `assets/fonts/` with their licences beside them.
- **Theme:** the catalog of a company of one: writings filed as RFCs and projects run as services, set like an archive index. The grid, type scale, spacing and colours are custom properties at the top of `assets/site.css`, and the rest of the file uses only those. Light is ink on paper. Dark is white on pure black. `⌘K` opens the palette. Escape on a filing goes back to the index.
