# internaltooling.github.io

Personal site of internaltooling, dressed as an equipment manual for one person. Plain HTML, no build step.

- **Typefaces:** Apfel Grotezk (display) and Ronzino (text) from [Collletttivo](https://collletttivo.it), Martian Mono (labels, code) by Evil Martians, found on [Uncut](https://uncut.wtf). All are SIL OFL 1.1 and self-hosted in `assets/fonts/`, with their licences beside them.
- **Theme:** hazard-yellow labels on warm manual paper, rubber stamps, a ⌘K jump menu, a fleet ticker, a machine rating-plate footer and a hazard-striped 404. The dark theme is the same manual read in a black plant room.
- **Inspiration:** [ghost.ai](https://ghost.ai) (big wordmark hero, banner strip), [gwern.net](https://gwern.net) (document-first essays, contents rail), [yuga.com](https://yuga.com) (stark black and white), [Making Software](https://www.makingsoftware.com) via httpster (technical-document captions), [Beckmans 2024](https://beckmans.college/2024/sv) via hoverstat.es (console as design), [Decimals](https://www.decimals.co) via footer.design, [CodeRabbit 404](https://www.coderabbit.ai/our404) via 404s.design.
